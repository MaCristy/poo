Abstração 
    > Tende a definir apenas aquilo(caracteristicas) que for essencial de um objeto, por isso os detalhes de 
    implementação não são mostrados.
        "Como deve fazer, mas não como ela fará"

Encapsulamento
    > Tem o foco em proteger certos dados de um objeto, os quais só seram acessados por meios "controlados".
        "Oculta dados internos de funcionamento, e mostra o necessario para o uso externo".

Herança
    > Uma classe vai reaproveitar os atributos e os metodos de outra classe, isso vai evitar o chamado "repetição de
    código".

Polimorfismo
    > Diferentes objetos possuem o mesmo metodos, porém são execultados de maneiras difeentes.
